# Project Instructions

Read `docs/design/design-reference.md` before implementing UI.

The files in `docs/design/` are visual references and represent the
source of truth for the interface.

Do not redesign the interface.

Do not introduce a different visual style.

When implementing a screen:
1. Identify the corresponding reference image.
2. Read its description in design-reference.md.
3. Inspect existing components.
4. Implement the screen.
5. Run the application.
6. Verify the result against the reference.
7. Fix visual discrepancies.

Do not change the architecture without a reason.

Do not remove existing functionality.

Do not use mock functionality when a real backend implementation is required.

Keep frontend and backend responsibilities separated.

Before finishing a task, run the relevant tests, type checks and linting.
